Privacy Policy

Last updated: November 2, 2026

GTA6 Autopilot is a personal tool run by its owner on their own computer. It uses the YouTube Data API only to upload videos to, and read basic information about, the owner's own YouTube channel.

Data we access

With the owner's permission, the app accesses the authorized YouTube channel's name and ID and uploads videos the owner has created. No data from other users is accessed.

How data is used and stored

Access tokens are stored only on the owner's computer. No data is sold, shared with third parties, or sent to any server other than Google's APIs.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
